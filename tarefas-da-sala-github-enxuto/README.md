# Tarefas da Sala

Painel responsivo para organizar tarefas, provas, trabalhos, avisos, comentários e progresso da turma.

## Como publicar grátis na Vercel

1. Suba estes arquivos para um repositório no GitHub.
2. Entre em https://vercel.com e clique em **Add New Project**.
3. Escolha o repositório.
4. Mantenha as configurações padrão de Next.js.
5. Clique em **Deploy**.

A Vercel vai gerar um link grátis parecido com:

```text
tarefas-da-sala.vercel.app
```

## Como usar

- O site abre direto no painel, sem login do ChatGPT.
- O nickname é escolhido em **Pessoas e permissões**.
- As tarefas, matérias, comentários e progresso ficam salvos no navegador do aparelho.

Para deixar os dados compartilhados entre todos os alunos em tempo real, conecte depois um banco grátis, como Supabase.
